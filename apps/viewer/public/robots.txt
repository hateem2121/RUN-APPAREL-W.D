# What may be done with this content: search=yes, ai-input=yes, ai-train=no
# https://contentsignals.org — a stated preference, not a technical block.
#
# ⚠️ THE SAME POLICY AS https://wear-run.help/robots.txt (owner decision 2026-09-11), and
# apps/cms/src/viewerRobots.test.ts fails if the two hosts drift. That file's list lives in
# apps/cms/htmlLimitedBots.mjs; this host serves public/ as plain files, so it is copied here.
#
# Everyone except the eight below may crawl everything. Every garment page is a
# link-preview target: apps/viewer/worker/index.ts rewrites per-garment Open Graph cards
# for crawlers, and the og:image it emits is /og/<product>/<colourway>.jpg on this host.
# Facebook's and Twitter's crawlers honour robots.txt when fetching og:image, so a
# Disallow on /og/, or refusing a link-preview crawler, would turn every shared link back
# into a generic card. A /og/ line was written and removed on 2026-08-31 for that reason.
#
# ⚠️ THIS FILE EXISTS TO STOP robots.txt BEING HTML. Until 2026-08-31 the build had no
# robots.txt, so the SPA fallback answered /robots.txt with index.html, which a crawler
# parses line by line as directives.
#
# ⚠️ ROBOTS.TXT ASKS; IT DOES NOT ENFORCE. Cloudflare's managed robots.txt and its
# "Block AI bots" rule were both switched off on 2026-09-04, so this file is the whole
# story. If refusal ever needs ENFORCING, that is a dashboard decision, and this comment
# should be corrected in the same change.
User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=no
Allow: /

# ⚠️ THESE READ ONLY TO TRAIN, and each has a sibling that answers and stays welcome under
# * above (OAI-SearchBot, Googlebot, Applebot, Claude-SearchBot, meta-externalfetcher,
# Amzn-SearchBot). No Allow line here: Allow: / would tie with Disallow: / and reopen the
# crawl for most parsers.
User-agent: GPTBot
User-agent: Google-Extended
User-agent: Applebot-Extended
User-agent: CCBot
User-agent: Bytespider
User-agent: ClaudeBot
User-agent: meta-externalagent
User-agent: Amazonbot
Content-Signal: search=yes, ai-input=yes, ai-train=no
Disallow: /
